# Plan — Trio v0.1

Owner: BA. Implements `spec.md` within `charter.md`. Each step is one builder unit (1–2 files; S3 is the one 3-file exception, explained there).
**Invariant:** after every step, `cargo check` on Windows exits 0. A step that breaks it is not done.
Every cargo run takes the build slot: write `docs/work/.build-lock` (owner, purpose, ISO timestamp) and delete it afterwards.

## Commands

**Windows (QA/Dev can run), from `E:\3touch\src-tauri`:**
```
cargo check
cargo test
cargo test gesture::          # state machine only
cargo test config::           # config only
cargo clippy -- -D warnings   # optional, if clippy installed
rustup target add aarch64-apple-darwin x86_64-apple-darwin           # once
cargo check --target aarch64-apple-darwin   # best effort: type-checks macos.rs, no linking
```
The cross check compiles our `cfg(target_os="macos")` code without the Apple SDK. If it fails **inside a dependency's build script** (SDK or `xcrun` needed), record that in impl-notes and treat the gate as Mac-only. If it fails **in our crate**, that is a real bug.
Frontend: open `E:\3touch\src\index.html?mock=ok` (also `off|noperm|error|both|savefail`) in Chrome/Edge with the DevTools device size set to 720×540.

**macOS only (no team machine; the owner or a future tester runs these):**
```
cd src-tauri && cargo test
cargo tauri dev               # needs: cargo install tauri-cli --version "^2"
cargo tauri build --bundles app
TRIO_DEBUG=1 cargo tauri dev  # per-frame contact log to stderr
TRIO_MT_PATH=/nonexistent cargo tauri dev   # AC-28
./scripts/dev-mac.sh
```

## Ordering rationale
- The riskiest macOS surface (S6/S7) lands right after the pure core and the platform seam, before config/UI. It is fully `cfg`-gated, so Windows stays green. The cross-target check is the only early signal the team can get.
- S8 (config) depends only on S3, so it can run in parallel with S6/S7 if two builders exist. They share only the one-line `lib.rs` `mod` edits; serialise those.
- The UI (S10/S11) depends on the S9 command/event names. The spec freezes them, so S10/S11 may start early against the mock.
